Connect Google Sheets sync

Your supplements will be saved to a Google Sheet you own — syncing automatically across every device. One-time setup takes about 5 minutes.

1
Create a Google Sheet

Go to sheets.google.com and create a new blank spreadsheet. Name it Supplement Scheduler. Copy the Sheet ID from the URL — it's the long string between /d/ and /edit.

2
Get a Google API key

Go to console.cloud.google.com → Create a project → Enable the Google Sheets API → Go to Credentials → Create an API Key. Then click the key → under API restrictions select Google Sheets API.

Also go to Application restrictions → choose HTTP referrers → add file://* (for local file use).

3
Make the Sheet accessible

Back in your Google Sheet, click Share → Change to anyone with the link → set to Editor. This lets your API key read and write to it.
